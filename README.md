# まるつけ帳

**【教育用】小学校の先生のための、テストの丸付け・分析支援アプリ**です。
テストの写真から解答欄を切り出して並べ、○✕をつけると、単元別・観点別（A・B・Cの目安つき）の得意・不得意を分析し、Excelに書き出せます。
（国語・算数・理科・社会・外国語・その他に対応／先生1人ずつ、自分の端末で利用）

## 公開版（AIなし）で使う ― 先生向け

**https://senzu3.github.io/edu-marutsuke-cho/** をiPadのSafariで開くだけで使えます。インストールやアカウント登録は不要です。

1. Safariで上のURLを開き、**共有ボタン →「ホーム画面に追加」**。以後はホーム画面のアイコンから開きます（Safariは、しばらく開かなかったサイトのデータを自動で消すことがあるため）
2. 「名簿・設定」で出席番号と名前を登録
3. 「テスト登録」で模範解答を撮影 → 名前欄を囲む → 解答欄を囲んで正答を入力
4. 採点：答案を撮ると解答欄が切り出されて並ぶので、見ながら○✕をタップ
5. ときどき「名簿・設定」→「バックアップを保存」で、データをファイルに保存してください

公開版の約束：

- **AIは使いません。** 名簿・答案の写真・採点結果は、**その端末のブラウザの中だけ**に保存され、どこにも送信されません（サーバーは画面の部品を配るだけです）
- 先生ごと・端末ごとにデータは別々です。ほかの先生や、公開した人からは見えません
- 使う前に、勤務校・自治体の情報セキュリティポリシー（端末で使ってよいサイトなど）を確認してください

### 公開のしかた（管理する人向け）

- `main` ブランチに push すると、GitHub Actions（`.github/workflows/pages.yml`）が公開版を書き出し、GitHub Pages に公開します
- 初回だけ、GitHub のリポジトリの **Settings → Pages → Source** を「GitHub Actions」にします
- 手元で公開版を作るときは `npm run build:static`（書き出し先は `.next-static/`）。APIの中継（`app/api/*/route.api.ts`）は公開版には含まれません

以下は、AIの読み取りも使える **Mac版**（自分のMacで起動し、同じWi-FiのiPadから使う）の説明です。

## 個人情報の取り扱い

- **名簿・採点結果・分析は、この端末のブラウザ（IndexedDB）の中だけに保存**します。サーバーには何も残しません。
- 採点時にAI（Claude）に送るのは、**端末内で名前欄を塗りつぶしたうえで切り出した「解答欄の画像」**と、「数字」「あまり」などの**答えの形のヒント**だけです。答案全体・氏名・出席番号・正答は送りません（正誤は端末内で判定）。
  - 補正・塗りつぶし・切り出しはブラウザ内（`lib/warp.ts`, `lib/grading.ts`）で行ってから送信します。
  - APIルートは、想定外の項目を含むリクエストを拒否します（`lib/ai.ts` の `.strict()`）。
- 答案全体の画像は、採点を確定したら破棄します（設定で保存も可能）。解答欄の切り出し画像は「問題ごとに並べる」確認のため端末内に残し、確認画面のボタンで削除できます。
- 実際の児童の答案で使う前に、勤務校・自治体の情報セキュリティポリシーを確認してください。

## セットアップ

```bash
npm install
cp .env.local.example .env.local
# .env.local を開いて ANTHROPIC_API_KEY=... を設定（https://console.anthropic.com で取得）
npm run dev
```

Macでは http://localhost:3000 を開きます。

**2回目からは、フォルダの中の「まるつけ帳を起動.command」をダブルクリックするだけ**で、起動してブラウザが開きます。使い終わったら、出てきたターミナルのウィンドウを閉じてください。
同じWi-FiにつないだiPadやスマホからは `http://(Macの名前).local:3000`（またはMacのIPアドレス）を開きます。

### AIなしモード（APIキーなし・費用なし）

APIキーを設定していないときは、自動で **AIなしモード** になります（キーがあっても「名簿・設定」で選べます）。

- 答案用紙の登録：解答欄を指で囲み、正答を自分で入力します（1テストにつき1回）
- 採点：答案を撮ると、解答欄が切り出されて並びます。画像を見ながら○✕をタップします。「残りを全部○にする」で、✕の問題だけ付ければ済みます
- いちばん速いやり方：**全員分を先に撮影だけして確定** → 「問題ごとに並べる」で、同じ問題の全員分の解答欄を並べて一気に○✕
- 画像はどこにも送りません。単元ごとの分析もAIありと同じように使えます（AIの読み取りがないので、別解の学習と誤りの傾向の推定はありません）

### デモモード（APIキーなしで試す）

`.env.local` に `DEMO_MODE=1` と書くと、AIを呼ばずに**ランダムなダミー結果**を返します。画面を試すためのものです。
実際に採点する前に、この行を消してください。

## 使い方

1. **名簿・設定**：出席番号と名前を登録（1行に `1 青木 さくら`。Excelからの貼り付けも可）
2. **答案用紙の登録（テストごとに1回）**：模範解答を撮影 → 四すみを自動検出してまっすぐに補正 → 名前欄を囲む → AIが問題番号・正答・単元・**解答欄の位置**を読み取り → 枠・正答・**答えの形**（数字／あまり／単位つき／ことば・式／記述）・**観点**を確認・修正
   - **裏面があるテスト**：「＋ 裏面もある」で裏面も撮影して登録（裏面に名前欄がなければ囲まなくてよい）。問題ごとに表・裏を選べます
   - **教科**：国語・算数・理科・社会・外国語・その他から選ぶ（前回の教科を覚えます）。ホーム・分析は教科で絞り込め、観点別とExcelのまとめは教科ごとに分かれます
   - **教員用の解答用紙**（任意）：教師用の解答（赤刷りなど）を撮影して登録。採点画面の「教員用の解答用紙」から、あとで登録・撮り直しもできます。端末内だけに保存し、AIには送りません
   - **観点**（知識・技能／思考・判断・表現／主体的に学習に取り組む態度）：問題ごと、または「表面の問題をまとめて」設定。用紙に観点が印刷されていればAIも読み取ります
3. **採点**：出席番号を選ぶ → 答案を撮影 → 四すみを自動検出（ずれていたら指で直す）→ 写りのチェック → 解答欄ごとに切り出してAIが書き写し → 端末内で正答表と照合 → 写真の上に赤い○✕ → 確定で次の人へ
   - 解答用紙を登録したテストは「解答用紙と並べる」で、答案全体と解答用紙を左右に並べ、問題ごとにも「児童｜解答」の切り出しを並べて見比べられます（確認画面も同様）
   - 裏面があるテストは、表と裏を別々に撮って1人分の点数にまとめます。順番は「1人ずつ表→裏」か「全員の表を先に」を選べます。片方だけ採点した児童は番号が点線になります
4. **確認**（「要確認をまとめて見る」）
   - **要確認だけ**：AIが迷った答えだけを、切り出し画像つきで一覧
   - **問題ごとに並べる**：クラス全員の同じ問題の答えを、同じ答えごとにまとめて表示。「まとめて○／✕」も可能
5. **分析**：クラス全体・児童別・テスト別に、単元ごとの正答率と、**観点別の得点率・A・B・Cの目安**を表示
   - 観点別の得点率＝その観点の得点の合計 ÷ 採点した問題の配点の合計。A・B・Cの基準（初期値：A 80%以上、C 50%未満）は設定画面で変更できます
6. **Excelに書き出す**（画面右上の緑のボタン。どの画面からでも押せます）：先頭に教科ごとの「単元別（算数）」「観点別（算数）」などのまとめ、そのあとにテストごとに1タブ（観点別の小計つき）
   - 「前のExcelファイルに追加する」で前回のファイルを選ぶと、新しいテストは新しいタブとして足し、同じテストのタブは最新の結果で上書きします。先生が自分で作ったタブは残ります
   - 元のファイルは書き換えず、更新したファイルを新しく保存します。「氏名も入れる」を外すと出席番号だけになります

## 採点ミスを減らす仕組み

AIへの問い合わせは**1人1回**（利用料をおさえるため）。そのぶん、読み取りの前後を端末内の処理で固めています。

| 段階 | 内容 |
|---|---|
| 四すみの自動検出 | 写真から白い用紙を見つけ、角を自動で合わせる。うまくいかないときだけ指で直す |
| 位置合わせ | 答案をテンプレートに重ね、解答欄を1つずつ切り出す。隣の問題との取り違えを防ぐ |
| 写りのチェック | ピンぼけ・暗さ・うすい写りを送る前に検出し、撮り直しをすすめる |
| 画像を読みやすく | 切り出した欄を白黒にして明るさ・コントラストを整え、小さい字は拡大してからAIに送る |
| AIは書き写すだけ | 正答を見せずに、書いてある通りに書き写させる（正答に引きずられた読み間違いを防ぐ）。2通りに読める字はもう一方の読みも返させる |
| 教科 | 登録時に教科を選ぶと、AIへの指示（縦書きの欄、英語のつづりをそのまま写す など）と答えの形の初期値が教科に合わせて変わる |
| 答えの形 | 「数字」「あまり」「単位つき」「記号」「漢字」「英語」「ことば・式」「記述」を登録。形に合わない読み取りは「要確認」、あまり・単位の書き忘れは自動で✕ |
| 記号 | 「ア」「(ア)」「ｱ」、「②」と「2」を同じとみなす。ひらがなの「あ」は「要確認」 |
| 漢字 | とめ・はね・はらいはAIでは判断しきれないので、正答と同じ字でも必ず先生が画像で確認（確認後「同じ字の漢字をまとめて○」）。漢字で書く問題をひらがなで書いた答えは自動で✕。別解としては覚えない |
| 英語 | つづり・大文字小文字を区別。大文字・小文字だけ違う答えは「要確認」。英文（2語以上）は正答と違えば「要確認」で、△もつけられる |
| ことば・記述 | 「ことば・式」は正答と書き方が違えば✕にせず「要確認」に。「記述」はAIが書き写した文と解答欄の画像を並べ、必ず先生が判定。どちらも△（部分点）がつけられる |
| 端末内で照合 | 表記ゆれ（全角・空白・「余り」・0.5と1/2など）をそろえて正答・別解と照合。誤りの傾向（くり上がり・位取り・あまりなど）も推定 |
| 先生の確認 | 要確認だけを一覧で確認。問題ごとの横並びで判断のぶれを防ぐ |
| 別解の学習 | 先生が○にした別の書き方を別解として登録し、同じ答えの他の児童も自動で○に |

## ファイル構成

| パス | 役割 |
|---|---|
| `lib/db.ts` | 端末内のデータ保存（Dexie / IndexedDB） |
| `lib/warp.ts` | 四すみの自動検出・台形補正・名前欄の塗りつぶし・解答欄の切り出し・画像の補正・写りのチェック（ブラウザ内） |
| `lib/judge.ts` | 表記ゆれの吸収・答えの形の確認・正答表との照合・誤りの傾向の推定・要確認の判定 |
| `lib/grading.ts` | 採点の流れ（切り出し → AIの書き写し → 端末内で判定 → 保存）と別解の学習 |
| `lib/ai.ts` | Claude APIの呼び出し（答案用紙の読み取り・解答欄の書き写し）・プロンプト・デモモード |
| `app/api/*` | AIへの中継（保存・ログ出力なし） |
| `app/tests/new` | 答案用紙の登録 |
| `app/grade` | 採点画面（URLは `/grade?id=テストの番号`） |
| `app/grade/review` | 要確認一覧・問題ごとの横並び確認 |
| `app/analytics` | 分析 |
| `lib/excel.ts`・`components/ExcelExport.tsx` | Excelへの書き出し（端末内で作成） |
| `samples/` | 動作確認用のサンプル答案（架空） |
